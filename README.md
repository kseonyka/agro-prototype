# Агро — мобильный прототип

Интерактивный прототип помощника в поле для агронома и руководителя.

## Запуск

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны.

Для запуска через локальный сервер выполните в папке проекта:

```sh
python -m http.server 8080
```

Затем откройте http://localhost:8080.

## Возможности

- Переключение ролей агронома и руководителя.
- Наблюдения, поля, случаи, планы и задачи.
- Локальное сохранение данных в браузере.

Все диагнозы, консультации и расчеты демонстрационные. Фотографии хранятся в браузере; внешние сервисы не подключены.

Исходник экспортирован из страницы «Агро — мобильный прототип» без изменений.
